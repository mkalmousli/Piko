# Contributing

Thanks for helping improve Piko!

- **Bugs / ideas**: open an issue using the templates. For bugs include device, Android version and steps.
- **Pull requests**: keep them focused; open an issue first for large changes.
- **Principles**: pure Android SDK (no new dependencies), small APK, fast startup, privacy first.
- **Build**: JDK 17 + Android SDK 34, then `./gradlew assembleDebug`. CI must pass.
- **Style**: match the surrounding Java (naming, comment density); no reformat-only changes.
